2 · 最后一批新朋友

这一批里有两个「关系户」：v 是 f 的浊音兄弟（咬唇位置相同，v 振动、f 不振），z 是 s 的浊音兄弟（咝音对）。另外 x 和 q 的读法有官方设定，认真看表：

字母字母名（背口诀用）字母音（拼读用）发音提示
j/dʒeɪ/ 「杰」/dʒ/嘴唇微突的「居」去掉元音，喉咙振动
v/viː/ 「维」/v/和 /f/ 一样咬唇，但喉咙振动——中文没有这个对立，重点练
w/ˈdʌbljuː/ 「达布留」/w/圆唇滑音，像快速吹蜡烛前的嘴型
x/eks/ 「艾克斯」/ks/短词里读 /ks/，像 box 结尾——一口气两个小音，但算一个音素位
y/waɪ/ 「外」/j/词首当辅音：yes 的 /j/（「耶」去元音）。长元音用法以后再学
z/ziː/ 「贼」/z/和 /s/ 一样的咝音，但喉咙振动——蜂鸣的「zzz」
q/kjuː/ 「扣」/kw/q 几乎总是拉着 u 一起出现（qu），读 /kw/：quiz, quit

3 · 拼读练习：毕业前的最后几个词

j + a + m

→ jam 果酱

v + a + n

→ van 厢式货车

b + o + x

→ box 盒子

s + i + x

→ six 六

q + u + i + z（qu 手拉手）

→ quiz 小测验

🎉 里程碑达成：26 个字母音全部解锁

从第 1 课的 4 个字母到今天，你已经能：

✅ 见词能读——上百个 CVC 单词（含 digraph ck 与双写 ll/ff/ss）
✅ 听音能写——听到陌生短词能拆音素、写出字母
✅ 识别英语拼写的基本套路：清浊对、双写、二字母组合

下一步（真正的大门已开）：去 Oxford Owl 免费电子书 挑一本分级读物——你会发现大量词都能自己读出来。遇到读不出的，多半是新的 digraph（sh, ch, th…），那是下一阶段（Phase 3）的内容。
