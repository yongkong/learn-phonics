2 · 新朋友：i, n, m, d

学完这 4 个，加上昨天的 s, a, t, p，你手里就有 8 个音素——这是《Letters and Sounds》Phase 2 的前两组（Set 1 + Set 2），足以拼出几十个真单词。

字母字母名（背口诀用）字母音（拼读用）发音提示
i/aɪ/ 「爱」/ɪ/短促的「衣」，嘴角微开——不是拼音的「衣」，更不是字母名「爱」
n/en/ 「恩」/n/舌尖抵上齿龈，声音从鼻子出来，像轻轻的「嗯——」
m/em/ 「艾姆」/m/闭紧嘴巴哼出的鼻音，摸喉咙有震动
d/diː/ 「地」/d/和 /t/ 同位置，但声带振动——把手放喉咙上能感到嗡嗡

3 · 拼读升级：8 个音素能拼出这些词

规则不变：辅音开头、元音居中——CVC 结构。先自己小声连读，再点整词验证。注意 si- 和 pi- 里那个新元音 /ɪ/：

s + i + t

→ sit 坐

p + i + n

→ pin 大头针

m + a + n

→ man 男人

t + i + p

→ tip 尖端；小费

n + a + p

→ nap 小睡

体会一下：元音一换，词就换了——sat → sit、tap → tip。一个元音音素改变整个词义，这就是为什么元音音要读准。
